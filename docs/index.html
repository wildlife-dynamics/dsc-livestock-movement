dsc-livestock-movement

Checks livestock block movements recorded in EarthRanger. For each Community/Zone, every movement's FROM blocks should be the blocks the previous movement went TO. The workflow lists every movement with a status, so missed, empty or duplicate entries can be found and fixed in EarthRanger after each survey.

Statuses

Movements are sorted by time within each Community/Zone. A movement can have more than one status, joined with ;.

StatusMeaningAn issue?
Valid movementFROM matches the previous movement's TONo
First recordThe first movement for that Community/Zone in the time range, with nothing to compare withNo
Missed movement: expected FROM […] (#serial, date)FROM doesn't match the previous movement's TO, which is shown with its serial number and dateYes
No movementFROM and TO are the same blocksYes
Empty FROM or TOOne side has no blocksYes
Duplicate entrySame Community/Zone, date, FROM and TO as another movementYes

Requirements

  • Access to an EarthRanger data source, set up as a connection, with a livestock_block_movement event type whose fields are titled Community/Zone, FROM and TO
