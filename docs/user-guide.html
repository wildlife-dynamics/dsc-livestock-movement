User Guide

How to load dsc-livestock-movement, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select dsc-livestock-movement from the templates list.

2. Data sources

  • Access to an EarthRanger data source, set up as a connection, with a livestock_block_movement event type whose fields are titled Community/Zone, FROM and TO

3. Settings

4. Run it and find the results

The workflow writes livestock_movement_validation.csv to the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS), and shows the Livestock Movement Validation table on its dashboard when it finishes.

The report has one row per movement: Serial Number, Previous Serial Number, Date, Previous Date, From, To, Community/Zone, Status and is_issue. Filter on is_issue to see only the problems.

Statuses

Movements are sorted by time within each Community/Zone. A movement can have more than one status, joined with ;.

5. Fix what it finds

Open each flagged movement in EarthRanger by its serial number and correct it there, then run the workflow again.

  • Missed movement: look at this movement and the one named in its status. Often one of them has a wrong date (a year typo moves it out of order), or a movement between them was never entered.
  • Duplicate entry: the same movement was entered twice; remove one.
  • Empty FROM or TO / No movement: fill in or correct the blocks.
